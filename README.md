# SoftwareProject-Team04

This is our airport kiosk website for the software engineering project. It’s just a demo for the presentation. You can click around and try the main features with sample data.

To try it, open [index.html](airport-kiosk-prototype/index.html) in your browser. No setup needed. If you wanna send it to someone, [download the ZIP](airport-kiosk-prototype.zip). There’s also a short [demo guide](airport-kiosk-prototype/README.md).

The website works offline. I left the Gemini key out of the GitHub version, so Travel help uses the built-in answers.
